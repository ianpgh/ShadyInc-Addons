# Writ This — beta testing releases

The installed addon directory and manifest ID are `WritTracker`. Use only explicitly approved beta test ZIPs, with their unchanged TOC version and SHA-256 checksum. Publish the versioned ZIP and `latest.json` together. Keep prior ZIPs for recovery. Do not publish player SavedVariables, credentials or private development data. This repository is public.

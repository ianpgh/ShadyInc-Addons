# EasyFollow — stable releases

This directory is reserved for approved EasyFollow releases for WoW Forever. Upload the unmodified, versioned ZIP (for example `EasyFollow_v1.7.4.zip`) and a `latest.json` manifest pointing to that ZIP, with its SHA-256 checksum. Publish both together after testing. Keep older ZIPs for rollback; never include unrelated addons, user SavedVariables, credentials, or private development builds.

The desktop manager reads the stable HTTPS manifest when checking for updates. Installations require user confirmation.

The initial 1.7.4 release is pending upload of its exact ZIP and manifest.
